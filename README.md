Сайт был разработан в рамках дипломной работы в 2026. Всё будет развиваться.
## Как развернуть проект
1) Скачать архив
2) Установить Node.js
	1) 'cd -имя папки-'
	2) 'node app.js'
	3) 'npm instal' для обновления библиотек
3) установить MySQL
	1) создать базу командами из .sql файла
